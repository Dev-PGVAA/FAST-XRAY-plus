# XrayForge

Универсальный установщик VPN-сервера для чистого Ubuntu/Debian VPS: Xray-core (VLESS+REALITY, Shadowsocks), Telegram MTProto-прокси, Cloudflare WARP, мониторинг ресурсов и базовый харденинг — всё в одном интерактивном скрипте с чек-бокс меню выбора компонентов.

Форк [FastXray_MTProto](https://github.com/Dev-PGVAA/FastXray_MTProto), расширенный до полноценного конструктора сервера.

## Что делает скрипт

- Ставит **Xray-core** с VLESS+REALITY (основной + резервный порт) и Shadowsocks
- Опционально поднимает **Telegram MTProto**-прокси (mtg)
- Опционально ставит **Cloudflare WARP** и маршрутизирует Google-трафик (`geosite:google`) через него отдельным outbound'ом — фикс ситуаций, когда сервисы Google определяют геолокацию неверно из-за репутации IP-подсети хостера, а не по факту его регистрации
- Опционально ставит утилиты **мониторинга ресурсов**: `btop`, `htop`, `iotop`, `ncdu`, `vnstat`, `iftop`
- Опционально включает **fail2ban** (бан за перебор SSH-паролей) и **unattended-upgrades** (автообновления безопасности)
- Опционально включает **BBR** congestion control для более стабильного туннеля
- Создаёт отдельного пользователя с sudo, настраивает SSH (пароль/ключ/оба), может отключить root-логин
- Настраивает `ufw` под используемые порты
- Генерирует готовые ссылки для клиентов (vless://, ss://, tg://proxy) и QR-код для MTProto
- Всё опциональное выбирается через **интерактивное чек-бокс меню** (↑/↓ — навигация, Пробел — вкл/выкл, Enter — подтвердить)

## Требования

- Чистый VPS на Ubuntu 20.04+/Debian 11+
- Root-доступ
- Публичный IPv4-адр9с

## Установка

```bash
curl -O https://raw.githubusercontent.com/DEV-PGVAA/XrayForge/main/setup_vpn.sh
bash setup_vpn.sh
```

Скрипт задаст несколько вопросов (имя сервера, создание пользователя, способ входа по SSH, отключение root-логина), затем откроет чек-бокс меню дополнительных компонентов — по умолчанию выбрано всё, снимайте пробелом то, что не нужно.

## Компоненты меню

| Компонент           | Что делает                                                                                                                 |
| ------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| Telegram MTProto    | Поднимает `mtg` на отдельном порту, генерирует ссылку и QR для Telegram                                                    |
| Cloudflare WARP     | Ставит `warp-cli`, добавляет outbound в Xray, роутит Google-домены через WARP, включает watchdog-таймер на переподключение |
| Мониторинг          | `btop`/`htop`/`iotop`/`ncdu`/`vnstat`/`iftop` — CPU, RAM, диск, сеть                                                       |
| fail2ban            | Бан IP на 1 час после 5 неудачных попыток SSH за 10 минут                                                                  |
| unattended-upgrades | Автоустановка security-патчей ОС                                                                                           |
| BBR                 | Тюнинг TCP congestion control для более стабильной пропускной способности туннеля                                          |

## После установки

Все ссылки и пароль пользователя выводятся один раз в конце установки и сохраняются в:

```
/usr/local/etc/xray/client_configs/README.txt
```

Скопируйте эти данные сразу — повторно скрипт их не покажет.

### Импорт в клиент

Поддерживаемые клиенты: v2RayTun/NekoBox (Android), Streisand/Shadowrocket (iOS), v2RayN/Hiddify (Windows), Hiddify/V2Box (macOS).

Вставьте любую из ссылок (`vless://`, `ss://`) через «Добавить конфиг по ссылке», либо весь набор через «Импорт по base64».

## Полезные команды после установки

```bash
systemctl status xray            # статус Xray
systemctl status mtg             # статус MTProto-прокси (если включен)
warp-cli status                  # статус WARP (если включен)
btop                             # монитор CPU/RAM/диск/сеть (если установлен)
journalctl -u xray -n 50         # логи Xray
```

## Безопасность

Скрипт по умолчанию отключает root-логин по SSH, настраивает `ufw` в режиме deny-by-default и умеет ставить `fail2ban`. Тем не менее рекомендуется:

- Использовать вход по SSH-ключу вместо пароля, где это возможно
- Регулярно проверять `journalctl -u fail2ban` на предмет активности сканеров
- Держать зарезервированную копию `client_configs/README.txt` в надёжном месте
